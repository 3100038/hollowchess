# Hollow Chess

Hollow Chess is a lightweight browser-based chess game built for fast local play.

## How to run

1. Open `index.html` in a browser, or
2. Serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Game features

- Classic 8x8 chess board
- Turn-based play for two players
- Legal move generation for pawns, rooks, knights, bishops, queens, and kings
- Capture tracking and move highlighting
- Reset button for quick restarts

## Controls

- Click a piece to select it
- Click a highlighted square to move
- Click the same square again to deselect

## Notes

This is a simple, polished chess prototype designed to be easy to run and easy to extend.
